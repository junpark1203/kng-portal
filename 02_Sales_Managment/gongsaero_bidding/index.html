공식 가이드
기본 공식
납품단가 = 정산단가 + 수수료(6%) (공새로 수수료율: 약 6%)
수수료 계산 2대 대원칙
  • 최소 수수료 1원 보장: 계산된 수수료가 1원 미만이라도 무조건 최소 1원 부과
  • 단수 처리 규칙:
    • 절삭 정산단가 → 수수료 산출 시: 소수점 이하 버림(Math.floor)
    • 올림 납품단가 → 정산단가 역산 시: 소수점 이하 올림(Math.ceil)
구간별 상세 계산식
계산 방향 기준 구간 수수료 및 단가 산출 공식
정산단가 → 납품단가
(희망마진 기준)		 16원 초과 수수료 = Math.floor(정산단가 × 0.06)
납품단가 = 정산단가 + 수수료
(예: 1,280원 → 수수료 76원 → 납품 1,356원)
1원 ~ 16원 수수료 = 1원 (최소보장), 납품단가 = 정산단가 + 1원
(예: 10원 → 수수료 1원 → 납품 11원)
납품단가 → 정산단가
(최종단가 역산)		 17원 초과 정산단가 = Math.ceil(납품단가 ÷ 1.06)
수수료 = 납품단가 - 정산단가
(예: 2,000원 → 정산 1,887원 → 수수료 113원)
1원 ~ 17원 수수료 = 1원 (최소보장), 정산단가 = 납품단가 - 1원
(예: 10원 → 정산단가 9원, 수수료 1원)
납품단가 1원 입력 주의: 납품단가를 1원으로 입력하면 최소 수수료 1원이 차감되어 정산단가가 0원이 됩니다. 반드시 최소 2원 이상 입력해야 공급사 정산금이 발생합니다.
